## 점수 규칙
참가자 수가 많을수록 기본 점수가 커지고, 정답 제출 순서가 빠를수록 높은 점수를 받습니다.
예: 참가자 5명이라면 1등 > 2등 > 3등 > 4등 > 5등 순으로 점수가 내려갑니다.
